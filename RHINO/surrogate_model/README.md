# RHINO Surrogate Modeling Layer

This layer trains, evaluates, and stores machine learning surrogate models for RHINO using engineered features produced by the feature extraction layer.

---

## Responsibilities

- Load ML-ready datasets generated by the feature extraction layer
- Split data into training, validation, and test sets
- Normalize input and output features
- Train neural-network surrogate models
- Save trained model artifacts and normalization statistics
- Evaluate surrogate performance on held-out test data
- Generate metrics and diagnostic plots

---

## Inputs

Generated by:

```text
RHINO/feature_extraction/
```

Primary input:

```text
rhino_features.csv
```

---

## Workflow

```text
rhino_features.csv
          │
          ▼
  Train / Validation / Test Split
          │
          ▼
      Normalization
          │
          ▼
      MLP Training
          │
          ▼
   Best Validation Model
          │
          ▼
      Model Artifact
          │
          ▼
     Test Evaluation
```

---

## Files

### `trainSurrogate.py`

Trains the RHINO surrogate model.

Functions:

- Load feature dataset
- Split train / validation / test data
- Normalize inputs and outputs
- Train MLP surrogate
- Select best validation model
- Save model artifact
- Save training history
- Save train/validation/test split information

Outputs:

```text
artifacts/
├── rhino_surrogate.pt
├── training_history.csv
└── split_indices.json
```

---

### `testSurrogate.py`

Evaluates a trained surrogate model on the held-out test set.

Functions:

- Load trained model artifact
- Reconstruct test dataset
- Generate predictions
- Compute regression metrics
- Generate diagnostic plots

Outputs:

```text
artifacts/
├── metrics.json
├── test_predictions.csv
├── parity_plots.png
└── error_plots.png
```

## Saved Model Artifact

The trained model is stored as:

```text
rhino_surrogate.pt
```

Contents:

- Model weights
- Network configuration
- Input feature names
- Output feature names
- Input normalization statistics
- Output normalization statistics

This artifact is sufficient to reconstruct the surrogate and perform inference without access to the original training workflow.

---

## Example Usage

Train surrogate:

```bash
python trainSurrogate.py
```

Evaluate surrogate:

```bash
python testSurrogate.py
```
