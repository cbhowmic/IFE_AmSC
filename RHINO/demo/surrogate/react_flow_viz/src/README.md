# Overview
This folder is to develop a 2D interactive visualization of a facility using React Flow. 
The data is generated by a Python script using other files and generates a JSON files for nodes and edges.

The facility is made of components/subsystems where Tritium flows around. 

Each component has its name, index/id, a list of injectors, and a list of fractional inflows (one per injector).
Some components do have injectors but 'None' for inflows. 
That's because they are loss components where T is lost through the walls. 

# Goal
The goal is to develop an interactive visualization of the facility where the user can see the Tritium flow around the facility.
The user should be able to see the Tritium flow in real time and see the changes in the facility.
The user should see the facility layed out as in a planimetric view, with the components and connections between them.
When the Play button is pressed, the Tritium flow starts and the user can see the changes in the facility in real time. 
The user should se the components filled in time. 
The filling factor is proportional to the current mass of the component, relative to the steady state mass.
The steady state mass in the mass at equilibrium.
When T reaches the steady state mass, the component is filled to 100%.
When T reaches twice the initial mass, the component glows red.
When T reaches half the steady state mass, the component glows yellow.
If both are true, the component glows green.

The user should be able to pause the animation and reset the time to 0.
The time should be the physical time in days (this information is now missing from the data).
The user should be able to see the time index and the current mass of the component.
