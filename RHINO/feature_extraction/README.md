# RHINO Feature Extraction Layer

This layer converts RHINO campaign-index metadata into ML-ready datasets
for surrogate modeling and downstream analysis workflows.

The feature extraction workflow operates on campaign indexes (`.acx`)
generated by the campaign management layer and uses reusable SQL queries
to extract scientific features and targets.

---

# Responsibilities

- Execute reusable SQL queries on RHINO campaign indexes
- Extract scientific metadata and simulation outputs
- Build ML-ready tabular datasets
- Join features and targets across RHINO runs
- Export datasets for surrogate training and analysis

---

# Inputs

- RHINO campaign index (`.acx`)
- SQL queries from `campaign/queries/`

Example inputs:

```text
IFE/rhino.acx
campaign/queries/steady_state_time_all_runs.sql
campaign/queries/tritium_steady_inventory.sql
```

---

# Outputs

- Pandas DataFrames
- CSV training datasets
- ML-ready feature tables
- Surrogate-model input/output datasets

Example outputs:

```text
outputs/rhino_training_dataset.csv
outputs/rhino_training_dataset.parquet
```

---

# Workflow Overview

```text
RHINO outputs (.bp5)
    ↓
Campaign archives (.aca)
    ↓
Campaign index (.acx)
    ↓
SQL queries
    ↓
Feature extraction
    ↓
Training dataset
    ↓
Surrogate training
```

---

# Files

## `query_campaign_index.py`

Utility functions for interacting with RHINO campaign indexes.

Responsibilities:

- connect to `.acx` indexes
- execute SQL queries
- load results into pandas DataFrames
- provide reusable query interfaces

---

## `build_training_dataset.py`

Main dataset-generation workflow.

Responsibilities:

- execute feature queries
- execute target queries
- merge/join extracted metadata
- build ML-ready datasets
- export CSV/parquet outputs

---

## `config_features.yaml`

Central configuration for feature extraction workflows.

Defines:

- campaign index locations
- query lists
- join keys
- output dataset paths
- dataset-generation settings

---

## `inspect_training_dataset.py`

Utility script for validating and inspecting generated datasets.

Example checks:

- missing values
- dataset dimensions
- feature distributions
- target statistics

# Notes

- Feature extraction is query-driven.
- SQL handles scientific filtering and metadata selection.
- Python handles DataFrame construction and ML dataset assembly.
- Campaign indexes (`.acx`) are SQLite-backed and queried using `sqlite3`.
